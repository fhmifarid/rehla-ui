# Rehla UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename and restructure the existing Medusa UI design system monorepo into a single publishable npm package `@rehla-ui/ui` (with sub-path exports for icons and Tailwind preset) while preserving all component behavior, design tokens, and tests.

**Architecture:** Keep the existing Yarn 3 + Turborepo monorepo shape for developer ergonomics. Delete the `packages/icons/` and `packages/ui-preset/` standalone packages and consolidate their contents inside `packages/ui/` as sub-modules (`src/icons/`, `src/preset/`). Replace the manual `tsc + tsc-alias` build with `tsup` for multi-entry ESM/CJS outputs. Tailwind CSS is built via the standalone `tailwindcss` CLI into `dist/styles.css`. All `@medusajs/*` references are rewritten to `@rehla-ui/*`.

**Tech Stack:** Yarn 3.5.1 workspaces, Turborepo, TypeScript 5.1.6, React 18, Tailwind CSS 3.3, Vitest 0.32, Storybook 7.0, tsup 7.1, Radix UI primitives, clsx + tailwind-merge, class-variance-authority 0.6.1 (patched).

**Spec:** `docs/superpowers/specs/2026-09-03-rehla-ui-design.md`

## Global Constraints

- npm scope: `@rehla-ui` (decided during brainstorming).
- First publish version: `1.0.0` for all renamed packages.
- Public packages: `@rehla-ui/ui`, `@rehla-ui/eslint-config`, `@rehla-ui/tsconfig`.
- Private packages (workspace only): `@rehla-ui/toolbox`, `@rehla-ui/figma-api`.
- Root workspace name: `rehla-ui-monorepo` (private).
- All CSS variable names and Tailwind class names (`bg-ui-bg-base`, `--ui-fg-base`, etc.) MUST remain unchanged — no visual regression.
- All component prop APIs MUST remain unchanged.
- Existing 13 `*.spec.tsx` test files MUST pass without modification.
- Verification gate: `node scripts/rename-verify.mjs` MUST print `0 occurrences of @medusajs` across `packages/**`, `configs/**`, `tools/**`.
- Verification gate: `cd packages/ui && yarn pack --dry-run` MUST produce a tarball containing `dist/esm/index.js`, `dist/cjs/index.js`, `dist/esm/icons/index.js`, `dist/cjs/icons/index.js`, `dist/esm/preset/index.mjs`, `dist/cjs/preset/index.js`, `dist/styles.css`.
- We do NOT publish to a real npm registry in this iteration; we dry-run only.

- [ ] **Step 4: Create the `rename-verify.mjs` script**

Create `scripts/rename-verify.mjs`:

```js
#!/usr/bin/env node
import { readdirSync, readFileSync, statSync } from "node:fs"
import { join, relative } from "node:path"

const ROOTS = ["packages", "configs", "tools", ".github", "."]
const PATTERNS = [
  /@medusajs\//g,
  /\bmedusa-ui\b/g,
  /\bMedusaIcon\b/g,
  /\bmedusaUi\b/g,
]
const SKIP_DIRS = new Set(["node_modules", "dist", ".git", ".yarn", ".next"])
const SKIP_FILES = new Set(["yarn.lock", "rename-verify.mjs"])

let total = 0

function walk(dir) {
  for (const name of readdirSync(dir)) {
    if (SKIP_DIRS.has(name)) continue
    const full = join(dir, name)
    const st = statSync(full)
    if (st.isDirectory()) {
      walk(full)
    } else if (st.isFile()) {
      if (SKIP_FILES.has(name)) continue
      scan(full)
    }
  }
}

function scan(file) {
  const text = readFileSync(file, "utf8")
  const lines = text.split(/\r?\n/)
  for (let i = 0; i < lines.length; i++) {
    for (const re of PATTERNS) {
      const matches = lines[i].match(re)
      if (matches) {
        total += matches.length
        console.error(`${relative(".", file)}:${i + 1}: ${lines[i].trim()}`)
      }
    }
  }
}

for (const root of ROOTS) {
  try {
    const st = statSync(root)
    if (st.isDirectory()) walk(root)
    else if (st.isFile()) scan(root)
  } catch {
    // missing path is fine
  }
}

console.log(`\n${total} occurrences of @medusajs* / medusa-ui* / MedusaIcon* / medusaUi*`)
if (total > 0) {
  console.error("FAIL — rename is incomplete.")
  process.exit(1)
}
console.log("PASS — no occurrences remain.")
```
