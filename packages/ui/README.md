# @rehla-ui/ui

Rehla UI — React components, hooks, icons, and Tailwind preset for the Rehla (رحله) project.

```sh
yarn add @rehla-ui/ui
```

```tsx
import { Button } from "@rehla-ui/ui"

export const App = () => <Button variant="primary">Hello Rehla</Button>
```
